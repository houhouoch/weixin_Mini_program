# 今天还能花｜视觉系统

**平台：** 原生微信小程序

**方向：** 温暖编辑插画、纸张票据、强信息层级

**完成度：** 探索性高保真单页

## 设计原则

1. 第一眼先看到“今天还能花多少”，第二眼知道“钱花去了哪里”。
2. 用原创消费场景插画建立记忆点，不用 emoji、图库人物或装饰性 3D。
3. 内容区采用预算轨道、记录台和纸质小票三种不同结构，避免圆角白卡连续堆叠。
4. 颜色少而明确；不使用装饰性渐变和厚重阴影。
5. 动态文字使用微信系统字体；图片不包含需要随数据变化的文字。

## 字体

- 字体栈：-apple-system、BlinkMacSystemFont、Segoe UI、PingFang SC、Microsoft YaHei、sans-serif。
- 主金额：66–96rpx，800 以上字重，按长度降级。
- 页面标题：44rpx；模块标题：40–44rpx；记录标题：29rpx。
- 正文：22–26rpx；辅助信息不小于 19rpx。
- 不加载网络字体，不用手写体模仿生活感；生活感由插画和纸张结构承担。

## 几何与间距

- 页面水平内边距 32rpx；大模块间距 32rpx。
- 主视觉圆角 56rpx；记录台 48rpx；预算轨道和分享区 36rpx。
- 小票不使用圆角，采用 3rpx 虚线边框和浅色分隔。
- 主要操作目标至少 88rpx；分类快捷项不得因文案变化而跳动。

## 组件状态

- 分类：默认浅纸色，选中为森林绿反白。
- 保存：空闲、保存中、成功、失败；保存中禁用重复点击且按钮尺寸不变。
- 预算轨道：正常为奶油黄；额度将尽为琥珀黄；今日超额为珊瑚红；本月超支使用更深危险色。
- 主视觉状态：标题、金额/状态文案、进度和标签同步变化，不能只换轨道颜色。
- 记录：分类标签 + 用途 + 时间 + 金额；用途为空时显示分类名。
- 分享：好友为实体黄按钮；朋友圈为描边引导按钮。

## 主题与语义色

- 预设主题：暖森林、海岸蓝、日落珊瑚、午夜、青柠、黑白。
- 用户可微调主色、背景温度和亮度；系统派生正文、表面、边框和按钮对比色。
- `warning` 与 `danger` 是固定语义 token，不受主题覆盖；任何主题下都必须保留可读文字色。
- 主题切换实时预览并可恢复默认，不允许自由输入任意十六进制色值。

## 消费回看

- 采用 `日｜月｜年` 单一分段控件；默认日视图。
- 图表仅使用低密度柱状趋势和关键数字，不使用饼图、环形图、仪表盘或多轴图。
- 缺少真实历史时显示数据范围说明，不用估算值补图。

## 禁止

- 连续白色圆角卡片、玻璃拟态、霓虹渐变、无意义光球。
- 网络字体、第三方 UI 库、emoji 功能图标。
- 把主视觉文字烘焙进图片。
- 用装饰牺牲对比度、触控面积、错误提示或窄屏可用性。

## 交付检查

- 375px 无横向裁切。
- 主要触控区域约 88rpx。
- 超长金额字号降级。
- 系统字体变化不遮挡金额与按钮。
- 图片来自仓库本地路径。
- 分享文案不出现逐笔明细或身份字段。
