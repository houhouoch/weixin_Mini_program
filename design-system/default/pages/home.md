# Apple 6.0 页面规则

首页 175:80 / 石墨 175:168：日期与状态 → 安全额度 → 今日已花、建议日均、进度 → 周期及计算说明 → 本周期省下（注明已扣储蓄目标）→ 文字/语音 → 最近记录。原生状态栏与微信胶囊由微信提供，不重复绘制。

账单 175:256：月度总额 → 收支切换 → 纵向消费日历（往月导航、每天金额、点选当日明细）→ 平滑日走势及数值刻度 → 分类与流水。未来日期不画成真实零支出。保留全部范围、修改删除、导入预览和批次撤销。

确认 175:485：原文可改，每笔金额、用途、收支、分类和时间可改；选中状态可取消，底部确认前不写账本。失败保留文字，支持本机手动录入。

设置 175:546：预算、周期、双主题、减少动态效果、导入导出、完整备份恢复；更多工具保留原有手动记账、模板、历史和日/月/年/自定义分析与分享。所有数据错误原位显示。
