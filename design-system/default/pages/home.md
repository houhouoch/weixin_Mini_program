# 首页视觉覆盖规则

本文件覆盖 `../MASTER.md` 中与产品不符的深色背景、网络字体和通用落地页建议。

## 方向

- 产品：个人日常预算工具，微信小程序单页。
- 气质：明亮、可信、友好、轻量；不做银行后台，也不做幼稚卡通。
- 布局：移动端单列；主金额卡占首屏最高视觉权重；表单和列表服务于结果。

## 色彩 Token

| Token | Value | 用途 |
|---|---:|---|
| `page-bg` | `#F3F7F2` | 页面背景 |
| `surface` | `#FFFFFF` | 普通卡片 |
| `primary-700` | `#126B52` | 主按钮、重点文字 |
| `primary-600` | `#16805F` | 核心卡主色 |
| `primary-500` | `#20A878` | 核心卡辅助色 |
| `primary-100` | `#DDF4E9` | 柔和状态背景 |
| `ink-900` | `#16231D` | 主文字 |
| `ink-600` | `#52645B` | 次级文字 |
| `ink-400` | `#66776E` | 辅助文字，满足浅色背景可读性 |
| `line` | `#E0E9E3` | 边框/分隔 |
| `warning` | `#D69A24` | 额度将尽 |
| `warning-bg` | `#FFF3D5` | 提醒背景 |
| `danger` | `#C84F4A` | 错误/超支 |
| `danger-bg` | `#FDE9E7` | 错误背景 |

允许核心结果卡使用非常克制的 `primary-600` → `primary-500` 线性渐变以建立层级；其他区域保持纯色。

## 字体与层级

- 使用微信系统字体栈：`-apple-system, BlinkMacSystemFont, "Segoe UI", "PingFang SC", "Microsoft YaHei", sans-serif`。
- 主金额 96–112rpx、700 字重、紧凑行高；超长数字按长度降级到 72–88rpx。
- 页面标题 30rpx/600；卡片标题 28rpx/600；正文不小于 26rpx；辅助文字不小于 22rpx。

## 几何与间距

- 页面水平内边距 32rpx；卡片间距 24rpx。
- 核心卡圆角 48rpx；普通卡 32rpx；输入和按钮 24rpx。
- 主按钮高度至少 96rpx；图标按钮命中区至少 88rpx。
- 阴影只用于核心卡和底部抽屉，低透明度、大模糊，不叠加多层重阴影。

## 交互

- 按压反馈使用 150–200ms 的透明度/轻缩放变化。
- 保存中按钮保持宽高不变并禁用重复点击。
- 输入错误就近显示；成功用轻提示，不移动主要布局。
- 底部抽屉保留底部安全区；遮罩点击不关闭首次必填设置。

## 禁止

- 深色全屏、手写字体、网络字体、emoji 功能图标、复杂图表、玻璃拟态、重 3D、长段教育文案、横向轮播。
