# 今天还能花 · 简约版

这是一个可单独导入微信开发者工具的独立原生小程序。它保留完整版的预算、收支、回看、账单、导出、备份和分享能力，重新设计为中性、简约、低操作成本的单页界面。

## 与完整版的关系

- 完整版仍位于上层项目，本目录不会覆盖它。
- 简约版使用独立本地存储：`today-can-spend:minimal:*`，在同一 AppID 调试时也不会读写完整版数据。
- 如需迁移数据，可在完整版生成 JSON 备份，再在简约版“账本与数据”中选择恢复。
- 本目录的 `project.config.json` 默认使用 `touristappid`，方便独立开发。正式预览、上传或发布前，请换成你自己的小程序 AppID。

## 首页结构

1. 今日额度与预算状态；
2. 今日已花、本周期可用或超支；
3. 常驻快速记账和常用模板；金额与保存直接可用，分类、用途和模板管理收进一层“补充信息”；
4. 可折叠消费回看；
5. 可折叠账本与数据工具；
6. 轻量分享入口。

视觉只使用中性灰阶、白色表面、一个用户强调色和锁定的警示色。没有渐变、装饰主图、虚线票据或多块高饱和背景。

## 功能

- 每月 1–28 日自定义预算周期；
- 固定收入、固定支出、储蓄目标和关联校验；
- 固定支出直接填写或明细合计；
- 支出与额外收入、分类、用途/来源和常用模板；
- 当日最近记录、指定日期历史、修改和删除；
- 日/月/年/自定义时间段消费回看、周总结、分类和流水下钻；
- 微信 `.xlsx/.csv` 与支付宝 `.csv` 官方账单本地识别、预览、去重、导入；
- 最近导入批次整批撤销；
- 全部真实流水导出 Excel，打开、转发和 PC 保存；
- JSON 完整备份、校验、恢复、转发和 PC 保存；
- 六套克制主题和安全微调；
- 好友分享与朋友圈右上角菜单引导；
- 读取、空、保存中、成功、失败、防重复、超支和额度将尽状态。

## 技术边界

- 原生 JavaScript、WXML、WXSS、JSON；
- 单页，无 tabBar、第三方 UI、运行时依赖、登录、云开发或后端；
- 金额以整数分保存和计算；
- 页面不直接访问缓存或文件系统；
- 交易服务仅公开 Promise API `addTransaction()` 和 `listTransactions()`；
- 账单只在本机解析，不上传，不保存平台交易单号原文；
- 分享不携带逐笔数据、预算金额、OPENID、昵称、头像或身份信息。

1. 打开微信开发者工具；
2. 选择“导入项目”；
3. 项目目录选择本文件夹：

   `C:\Users\admin\.codex\worktrees\30f1\小程序\today-can-spend-minimal`

4. 本地体验可继续使用 `touristappid`；需要真机预览、上传时，将 `project.config.json` 中的 `appid` 改为自己的 AppID；
5. 项目名可填写“今天还能花-简约版”；
6. 导入后先“编译”，再测试首次设置、快速记账、回看、账本和主题。

如果你希望把它发布成与当前线上小程序完全独立的第二个小程序，需要在微信公众平台申请第二个 AppID；仅创建独立文件夹不会自动生成新的微信小程序主体或 AppID。

## 数据公式

```text
可灵活支配 = 固定收入 + 本周期额外收入 - 固定支出 - 储蓄目标
今日建议 = max(可灵活支配 - 今天之前真实支出, 0) / 含今天的剩余天数
今天还能花 = max(今日建议 - 今日真实支出, 0)
本周期余额 = 可灵活支配 - 本周期真实支出
```

额外收入增加可用额度，但不进入“今日已花”、支出趋势或支出分类。固定支出明细只解释预算扣减，不生成流水，也不进入 Excel 或消费回看。

## 文件导入说明

- 微信：从微信支付账单邮件下载并先解压，把 `.xlsx` 或 `.csv` 发送到任意微信会话，再在小程序选择；
- 支付宝：导出官方交易明细 `.csv`，发送到微信会话后选择；
- 两个平台共用一个入口，按表头自动识别；
- 导入前先预览，用户确认后才写入；
- 还款、信用借还、投资理财、不计收支、无效状态、未来和超过 36 个月的记录会按规则跳过；
- 全额退款与关闭的原交易匹配时抵消，部分或跨期消费退款按退款收入导入。

## 验证边界

Node 测试和结构检查可以证明数据口径、服务接口和静态页面约束；CLI preview 可以证明开发者工具成功打包；Automator 可以证明模拟器中的页面状态、点击、输入和 Console。它们都不能代替真实手机上的系统分享面板、原生文件/日期选择器、数字键盘、动态大字号和不同设备安全区验证。
