# 功能等价清单

本清单用于防止视觉重写过程中漏掉完整版能力。除首页信息层级和默认展开状态外，简约版保持相同的业务接口、计算口径和隐私边界。

## 启动与预算

- [x] 读取中、首次空、损坏数据、读取失败、正常结果
- [x] 预算周期起始日 1–28 日
- [x] 固定收入、固定支出、储蓄目标
- [x] 固定支出直接填写 / 明细合计
- [x] 预算关联校验、修改、重置和跨月选择
- [x] 旧 schema 迁移与最多 36 个月归档

## 额度与记录

- [x] 正常、额度将尽、今日超额、周期超支、无可用额度
- [x] 今日建议、今日已花、周期可用/超支
- [x] 支出 / 额外收入与独立分类白名单
- [x] 用途/来源、金额校验、保存锁和命令幂等
- [x] 常用模板保存、一键记录和删除

## 回看与纠错

- [x] 日、月、年、自定义时间段
- [x] 周总结、分类占比、趋势和区间流水
- [x] 指定日期支出/收入合计和逐笔明细
- [x] 修改收支方向、分类、用途、金额和原月内日期
- [x] 删除二次确认和当前预算重新计算

## 平台账单、导出与备份

- [x] 微信 `.xlsx/.csv` 与支付宝 `.csv` 共用入口
- [x] 本地自动识别、GB18030、状态/还款/退款口径、预览和去重
- [x] 最近导入批次整批撤销
- [x] Excel 生成、打开、转发和 PC 保存
- [x] JSON 完整备份、校验、恢复、转发和 PC 保存

## 主题、分享与隐私

- [x] 六套主题、色调/温度/亮度微调和恢复默认
- [x] 锁定警示与危险语义色
- [x] 好友分享、朋友圈菜单引导和分享进入提示
- [x] 分享路径只带 `from=share`
- [x] 页面不直接访问缓存或文件系统
- [x] 账单不上传，不保存平台交易单号原文
- [x] 埋点、分享和普通页面不含逐笔金额或身份信息

## 简约版主动调整

- 快速记账从默认折叠改为常驻，少一次点击；
- 回看和账本仍渐进披露；
- 删除装饰插画、多主色大块、虚线票据和厚重阴影；
- 主题从“整页多色”收敛为“中性表面 + 单强调色”；
- 使用独立存储 key；旧数据通过完整备份迁移，而不是静默共享。
