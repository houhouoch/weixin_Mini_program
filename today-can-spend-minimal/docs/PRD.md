# PRD：今天还能花 · 简约版

- 文档状态：V1.0 设计与实现基线
- 日期：2026-08-13
- 产品形态：原生微信小程序、单页、本地存储、独立项目目录

## 1. 背景

现有版本功能完整，但首页同时使用多种高饱和色、插画、票据、虚线边框和多层卡片。用户反馈“画面太乱、不明了”，并希望界面像 Apple 系统应用一样简约、清晰。此次不是删减功能，而是在独立程序中重写信息架构和视觉表现，降低高频任务的操作次数。

## 2. 目标用户

- 收入相对稳定、希望知道每日安全消费额度的上班族和学生；
- 有工资或生活费，也可能有外快、奖金、报销、红包等额外收入；
- 不愿学习复杂财务概念，希望快速记录、偶尔回看和纠错；
- 会从微信或支付宝导出账单，希望本地导入后统一查看。

## 3. 产品目标

1. 打开 3 秒内看懂“今天还能花”、今日已花和本周期可用/超支；
2. 普通手工记录不再先展开模块，输入金额后可直接保存；
3. 常用模板继续支持一键记账；
4. 回看、历史和文件工具按需展开，首页首屏不展示完整高级功能；
5. 所有完整版业务能力、数据口径、错误恢复和隐私边界保持一致；
6. 375px 窄屏、Android/Huawei 安全区和大字号下仍清晰可用。

## 4. 信息架构

### 4.1 首页常驻

1. 安全区标题与设置入口；
2. 今日额度：状态标题、主金额、简短解释；
3. 预算摘要：今日已花、本周期可用/超支、进度；
4. 快速记账：支出/收入、模板、金额、分类、可选用途/来源、保存按钮。

### 4.2 渐进披露

- 消费回看：默认收起，标题行先显示日/月/年/自定义能力；展开后提供趋势、周总结、分类和区间流水下钻。
- 账本与数据：默认收起；展开后提供日期明细、修改/删除、账单导入、导入批次撤销、Excel、备份恢复。
- 分享：位于页面末尾的轻量操作，不使用大面积彩色 CTA。
- 设置：底部抽屉包含预算周期、固定收入、固定支出两种计算方式、储蓄目标和主题。

## 5. 关键操作简化

| 任务 | 完整版路径 | 简约版路径 |
|---|---|---|
| 手工记一笔 | 展开“快速记一笔”→填写→保存 | 首页直接填写→保存 |
| 常用模板 | 展开模块→选择模板 | 首页直接点模板 |
| 查看余额 | 识别插画卡、票据和进度 | 主金额 + 两项预算摘要 |
| 查看历史 | 展开记录区→选日期 | 展开“账本与数据”→默认今天 |
| 导入/导出/备份 | 多个并列大按钮 | 账本内按“导入、导出、备份”分组 |

## 6. 功能范围

- 预算周期 1–28 日，按工资或生活费到账日解释；
- 固定收入、固定支出、储蓄目标和关联校验；
- 固定支出“直接填写 / 明细合计”；
- 支出与额外收入、8 类分类、用途/来源、常用模板；
- 最近记录、指定日期历史、修改、删除和归档纠错；
- 日/月/年/自定义区间统计、分类构成、流水下钻、周总结；
- 微信/支付宝官方账单文件自动识别、预览、去重、导入和批次撤销；
- Excel 导出、打开、转发和 PC 保存；
- JSON 完整备份、预览、恢复、转发和 PC 保存；
- 六套克制主题与安全微调；
- 好友分享与朋友圈右上角引导；
- 跨天、跨自然月、跨预算周期和旧 schema 迁移。

## 7. 视觉系统

- 页面背景 `#F5F5F7`，主要表面 `#FFFFFF`，主文字 `#1D1D1F`，次级文字 `#6E6E73`，分隔 `#D2D2D7`；
- 默认强调色 `#0066CC`，同一页面层级不再并列第二个品牌色；
- 警示 `#9A6700`、超支 `#D70015`，同时配合状态文字；
- 微信系统字体，数字使用 tabular 风格和紧凑字距；
- 4/8px 节奏，分组圆角 12px 等效，按钮圆角 10px 等效；
- 无渐变、无装饰主图、无彩色大块、无虚线票据、无厚重阴影；
- 按压用透明度/背景变化，不改变布局尺寸。

## 8. 数据与隐私

- 全部数据保存在当前设备，简约版使用独立存储命名空间；
- 可通过现有 JSON 备份恢复完整版数据；
- 账单在本机解析，不上传，不保存平台订单号原文；
- 分享不携带逐笔数据、预算金额、OPENID 或身份信息；
- 不登录、不申请手机号、头像、昵称或位置权限。

## 9. 非目标

不增加多页面报表、tabBar、服务端、云开发、自动钱包同步、银行直连、AI 理财、投资建议、支付、广告、会员、多账户、自定义分类管理或复杂动画。

## 10. 成功标准

- 核心业务测试与完整版等价；
- 首页首屏只包含标题、额度、预算摘要和直接记账入口；
- 默认无需展开即可完成手工记账和模板记账；
- 全部触控目标至少 44px 等效，375px 无横向滚动；
- 自动化 Console 无错误/警告/异常；
- 官方 CLI 成功生成预览包，真实手机结果单独标记。
